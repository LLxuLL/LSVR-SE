# LSVR-SE 项目层次结构说明

## 项目概述
LSVR-SE (Language-Guided Semantic Editing in Single-View 3D Reconstruction) 是一个先进的3D重建和编辑系统，支持从单张图像生成可编辑的3D模型。

## 项目结构

## 数据格式要求

### 1. 图像数据
- **格式**: JPG, PNG, BMP
- **尺寸**: 建议224x224像素
- **颜色**: RGB彩色图像
- **命名**: 建议使用连续数字命名 (0001.jpg, 0002.jpg, ...)

### 2. 网格数据
- **格式**: PLY (推荐), OBJ, STL
- **内容**: 三角形网格
- **属性**: 顶点坐标、法线信息
- **命名**: 与对应图像同名 (0001.ply, 0002.ply, ...)

### 3. 文本数据
- **格式**: 纯文本文件 (.txt)
- **内容**: 自然语言编辑指令
- **编码**: UTF-8
- **命名**: 与对应图像同名 (0001.txt, 0002.txt, ...)

### 4. 示例数据内容
```
# images/0001.jpg - 建筑立面图像
# meshes/0001.ply - 对应的3D网格
# texts/0001.txt - 编辑指令
添加窗户

# images/0002.jpg - 室内场景图像
# meshes/0002.ply - 对应的3D网格
# texts/0002.txt - 编辑指令
移除门并添加窗户
```

## 环境配置

### 1. Python环境
```bash
# 创建虚拟环境
conda create -n lsvr_se python=3.9
conda activate lsvr_se

# 安装依赖
pip install -r requirements.txt
```

### 2. 硬件要求
- **GPU**: NVIDIA GPU with 16GB+ VRAM
- **CPU**: 多核处理器 (推荐16核+)
- **内存**: 64GB+ RAM
- **存储**: 100GB+ 可用空间

### 3. 软件依赖
- **PyTorch**: 1.12+ (CUDA 11.8+)
- **Transformers**: 4.21+
- **Open3D**: 0.15+
- **Streamlit**: 1.12+

## 启动和运行

### 1. 启动Web应用
```bash
# Windows
run.bat

# Linux/Mac
./run.sh
```

### 2. 启动训练
```bash
python train.py --config default --num_epochs 100 --use_wandb
```

### 3. 启动推理
```bash
python reasoning.py --mode single --image image.jpg --text "添加窗户"
```

## 故障排除

### 1. 模型文件缺失
```bash
# 手动下载预训练模型
huggingface-cli download google/vit-base-patch16-224
huggingface-cli download openai/clip-vit-base-patch32
```

### 2. 数据格式错误
- 检查图像格式和尺寸
- 验证网格文件完整性
- 确保文本文件编码正确

### 3. 内存不足
- 减小批次大小
- 使用快速配置模式
- 启用混合精度训练
